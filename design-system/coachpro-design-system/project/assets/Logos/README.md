# Logos

The CoachPro mark — "The Breakaway." Copy these files; never redraw the mark. Full usage rules are in the **Logo & mark** section of the brand book.

- `coachpro-mark.svg` — the primary mark, ink **`brand` vermilion (#f04e28)**. Use on `bg`, `surface` and dark grounds.
- `coachpro-mark-ink.svg` — single-ink mark in **ink (#17150f)**, for monochrome/light contexts.
- `coachpro-mark-paper.svg` — single-ink mark in **paper (#f7f4ef)**, for dark grounds, vermilion fills and darkened photography.
- `coachpro-appicon.svg` — app-icon tile: `brand` vermilion mark on an **ink (#17150f)** rounded tile (`radius-xl` at scale).

Each SVG carries its ink baked in because an `<img>`-placed SVG can't inherit `currentColor` — pick the right file rather than recoloring in CSS. Minimum mark size is 16px.
