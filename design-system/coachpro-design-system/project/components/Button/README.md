Actions, in four variants and three sizes. One `primary` per view — the single most important next step.

`variant="primary"` is `brand` vermilion with `on-brand` ink and is reserved for the main action on a screen (Add client, Save, Send check-in); never show two primaries competing. `secondary` is the bordered default for everything else; `ghost` is for low-emphasis and toolbar actions; `danger` (`neg`) is only for destructive actions and is never the brand accent. Sizes: `md` is default, `sm` for dense tables and toolbars, `lg` for marketing and empty-state CTAs. Pass `iconLeft`/`iconRight` (nodes from `CoachPro.Icon`), `full` to fill the container, `href` to render an anchor.

The focus ring is the shared `focus` token (2px, 2px offset); don't remove it. Labels are verb + noun in sentence case ("Assign program"), per Voice & tone. Keep button text to two or three words.
