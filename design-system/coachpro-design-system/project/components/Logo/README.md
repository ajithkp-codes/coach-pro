The CoachPro logo, as a live component — mark, wordmark lockup, and stacked lockup, theme-aware.

Use `variant="lockup"` (mark + wordmark) as the default in nav bars and the marketing header; `variant="stacked"` for square/narrow spots; `variant="mark"` for avatars, favicons, loading states and anywhere under 104px wide. `size` is the mark height in px and the wordmark scales from it. `tone` picks the mark ink: `brand` (default) on light or dark grounds, `paper` on photography/vermilion fills, `ink`/`current` for monochrome. The wordmark is always set in the `display` family and inherits `currentColor`, so place it on a ground that meets contrast.

Do: keep the clear space (see Logo & mark), and let the mark carry the vermilion. Don't: recolor the wordmark, stretch the lockup, or use the lockup below its 104px minimum — switch to the mark. The downloadable files live in the Logos asset group; this component renders the same geometry inline for in-app use.
